### 2026-11-12 — perplexity-computer — function batch 1 review fixes

- Why: both engines must agree, and a case that departs from a sentence on Microsoft's page must say so instead of reading as arithmetic or as a silent page.
- Evidence: branch-local, not accepted on `main`. The disagreement was confirmed by running both engines before the change and is gone after it. A sweep of 3,456 formulas put error values (`NA()`, `#N/A`, `#DIV/0!`, `1/0`, error cells and ranges, errors selected by `IF`, `IFERROR` and `CHOOSE`), text, logical values, empty arguments, ranges and arrays into every argument position of the 45 batch functions that take arguments, singly and in pairs, and compared Python with native Rust: 22 differences before the change, all `RANK` and `RANK.EQ`, none after.
